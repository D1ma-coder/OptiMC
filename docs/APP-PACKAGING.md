# Иконка и упаковка приложения

Сборка macOS приложения без запуска игры/GPU:

```sh
cargo build --release
target/release/optimc package-app .cache/OptiMC.app
```

Команда копирует исполняемый файл и оригинальную `icons/minecraft.icns` из импортированных ассетов после проверки размера и SHA-1 по asset index. Имя и bundle identifier остаются OptiMC. `--executable /absolute/path` позволяет явно выбрать исполняемый файл; по умолчанию используется текущий.

При запуске графического клиента напрямую иконка Dock также задаётся через AppKit на главном потоке. Для Windows/Linux используется официальная PNG-иконка окна. Новый код иконки включается после перезапуска клиентского процесса; упаковщик не открывает и не закрывает приложение. Графическая проверка после WindowServer incident не выполнялась.

Для 26.2 официальный ICNS имеет SHA-1 `f00657542252858a721e715a2e888a9226404e35`; `icon_32x32.png` — `af96f55a90eaf11b327f1b5f8834a051027dc506`.
