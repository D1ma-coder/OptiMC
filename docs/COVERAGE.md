# Аудит соответствия клиенту 26.2

Обновлено: 20 октября 2026. Цель пользователя — полное воспроизведение клиента с оптимизацией, включая все сущности и взаимодействия. **Общая цель не достигнута.** Встроенный сервер и одиночная игра исключены. CLI `demo` и `model` служат инструментами разработки, не игровыми режимами продукта.

| Требование | Что подтверждено | Что отсутствует / следующее действие |
|---|---|---|
| Rust и низкоуровневый runtime | Cargo/Rust + WGSL, Vulkan-only Instance; Java используется только отдельными временными reference tools | Проверка собранных дистрибутивов на Windows/Linux; пока runtime проверен на macOS/MoltenVK |
| Только внешний сервер | Одиночная игра удалена; Multiplayer и CLI play подключаются к внешнему серверу, показывают его чанки и закрывают сокет при выходе | Полноценное управление и все игровые системы ещё не подключены |
| Offline-mode login/config/play | Login/config/chunks/live window; исходящие movement/input/sprint/slot/flight; generation fencing и keepalive/EOF проверены TCP fixture | Inventory/chat/actions, точные условия player-loaded, дополнительные transitions, локальная velocity/attributes и полная синхронизация physics |
| Все официальные ресурсы | SHA-1 catalog: 5057 объектов + 19494 JAR resources/data; runtime читает извлечённые файлы | Не все звуки/шрифты/языки/material paths включены в движок |
| Все blockstates/модели | 1198 blockstates, 2657 моделей, 8661 variant, 86486 quad, 1230 использованных texture refs проходят audit | Не special/block-entity renderers; animation metadata, биомный tint, fluid geometry, AO/light emission и occlusion в мире ещё не завершены |
| Формат моделей 26.2 | Inheritance, slots/materials, variants/multipart, UV/uvlock, element rotations/rescale; shared baked cache; RemoteMesher использует position seed + 48-bit RNG/multipart reseeding с official goldens | Block-specific getSeed/offset overrides; отдельный model viewer пока выбирает deterministic ticket 0 |
| Визуальная геометрия | Все 32366 state IDs компилируются; Vulkan PNG stairs/fence/glass и живого server chunk осмотрены; секции переиспользуются, late block/material update попадает в окно | Fluid/special renderers, lighting/AO/biome tint/animation, точные occlusion rules, прозрачная сортировка внутри секции и проверка всех визуальных разновидностей |
| Все сущности | Декодируются add/move/rotate/head/motion/position sync/teleport/remove; Tracker хранит network state; TCP fixture проверяет движение и удаление | 158 entity type names определяются по официальному static report; остаются metadata, equipment, passengers, entity/block-entity модели, анимации, particles, эффекты, sounds и world renderer |
| Взаимодействия | Сериализаторы разделённых Attack/Interact 26.2, hand, LP hit point, secondary action | Picking/raycast/reach/cooldown, игровые hitboxes и отправка из окна, client prediction + server updates |
| GUI/инвентарь | Официальные sprites/font, GUI Scale алгоритм 26.2, hotbar, перенос/разделение стопок; HD→экран render slider | Полный inventory protocol, recipes, armor validation, drag distribution, все экраны/чат/accessibility/controls binding |
| Камера/физика | 20 Hz client prediction над RemoteWorld, official collision shapes/factors для 32366 states, step/fence/wall/sneak-edge tests; abilities/базовый flight, F5/bob, server corrections | 199 dynamic states и entity context, fluids/ladder/effects/vehicles/attributes, supporting block, точные eye/camera shapes и полная vanilla parity |
| LOD | Demo quadtree balance/hysteresis, ≥384 блоков полных граней, промежуточные уровни, vertex sharing, radius/frustum culling | Реальные чанки, пещеры/строения/material reduction, persistent cache и invalidation; вне server view distance нужна сохранённая информация |
| Оптимизация | Mesh reuse, bounded CPU/GPU streaming, shared model geometry, simple Low shaders, render-resolution control, CPU/GPU timing | Жалоба на ~230 FPS не устранена достоверно: измерены задержки queue.submit; нужны воспроизводимые игровые сценарии и batching/occlusion/allocator work |

Проверки нельзя интерпретировать шире их области. Полный resource/model audit доказывает разбор и ссылки геометрии, не готовность всех игровых блоков. Entity packet tests доказывают wire/state path, не наличие всех визуальных моделей. Успешный login не является готовой сетевой игрой.

Следующий крупный этап: registry-based entity dispatch, metadata/equipment и render/model extraction для всех групп сущностей, взаимодействия и inventory protocol; продолжить локальную velocity/attributes, жидкости и динамические collision cases. Параллельных агентов не запускать без явного запроса пользователя. Каждая следующая итерация должна обновлять фактические пробелы, а не объявлять очередной прототип завершением клиента.


Этап registry/NBT (20 октября): добавлены полный binary NBT с UTF-16/modified UTF-8 и общим бюджетом пакета, configuration registry data, login/respawn headers, height-aware RemoteWorld, single/section updates и chunk unload. Статические ID получены официальным data report tool: 95 registries / 158 entity types / 32366 block states; gzip-данные (~291 КиБ) встроены в Rust binary, SHA-1 проверяются. Ни генератор, ни JDK не нужны клиенту при запуске. Client RemoteWorld хранит полученные чанки, а не генерирует или симулирует серверный мир.

Этап фоновой сессии (20 октября): CLI connect использует общий SessionMachine в отдельном worker; FrameBuffer сохраняет частичные пакеты при timeout и корректно меняет compression между буферизованными пакетами. API отдаёт только последний immutable snapshot и закрывает сокет при отмене без join. TCP fixture проверяет реальные паузы 40 мс, liveness, позу/скорость из teleport и отмену незавершённого пакета. RemoteWorld snapshots разделяют Arc columns/sections с copy-on-write; неизменность старых снимков проверена. Окно пока не использует этот API: основное следующее действие — подключить его к UI, mesher/render и управлению.

Этап server meshing (20 октября): RemoteMesher компилирует все 32366 state IDs (6812 parts / 1228 sprites), использует position-seeded weighted/multipart selection, скрывает полные opaque cullface грани через границы секций и переиспользует meshes по семи Arc-зависимостям. `connect --screenshot` подтверждён сквозным TCP → RemoteWorld → official models → Vulkan PNG тестом; `.cache/server-world.png` осмотрен. Это статический снимок после отключения, не live graphical multiplayer. Нужны постоянное обновление окна из Connection, mesh worker/texture streaming, обратная отправка ввода, fluid/special renderers, vanilla lighting/tint, точные occlusion rules, block-specific seed/offset, translucent sorting внутри секций и texture paging для GPU с низким array limit.

Этап live window (20 октября): Multiplayer/CLI play подключают Connection к отдельному mesher worker и постоянному Vulkan-рендеру. Новые слои текстур и meshes загружаются порциями; snapshots coalesce; epoch/position readiness защищают переходы мира. Проверены late block/material update во время рендера, keepalive и EOF на выходе, Connect/Cancel GUI; `.cache/server-live.png` осмотрен. Это закрывает пробел постоянного отображения чанков, но не полноценного управления: физика RemoteWorld, исходящие movement/input/rotation, abilities, entity visuals, inventory protocol, interaction и остальные строки матрицы пока незавершены. Сетевая камера стоит в серверной позе и поддерживает локальный mouse look; demo terrain и demo inventory не используются для подключения.

Этап movement/collision (20 октября): из official JAR экспортированы 326 AABB-наборов для всех 32366 state IDs (gzip 10098 bytes), collision context ограничен empty baseline, 199 dynamic flags сохранены. RemoteWorld physics/input/rotation/sprint/slot/базовый flight связаны с сетью по 20-Hz callback; 64-tick queue fenced by world/teleport/abilities versions. Проверены slab/fence/wall/unloaded-border/Shift-diagonal/flight, movement packet threshold/heartbeat и TCP stale-command rejection; живое окно посылает falling/landing positions и сохраняет keepalive. Это не доказывает готовность всех физик/механик: fluids, effects, moving/dynamic collision, supporting block, attributes/local velocity, entity interaction/visuals и inventory/chat/actions остаются обязательными пробелами.
