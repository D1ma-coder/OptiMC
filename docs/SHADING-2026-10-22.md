# Разделение цвета материала и направленного затемнения

Найдена ошибка в Enhanced terrain path: remote_mesh записывал в Vertex.tint
цвет материала, умноженный на directional shade (X 0.65 / Z 0.78). FS пытался
восстановить исходный цвет делением на коэффициент, выбранный заново из normal.
Для X/Z коэффициенты были перепутаны; компенсация действовала только при lod==0,
поэтому результат менялся и при переходе LOD. shade:false также терялся при
таком восстановлении. Это конкретные обнаруженные причины неверной яркости,
а не доказательство воспроизведения пользовательского кадра на GPU.

Добавлен отдельный Vertex.shade (f32, location15, offset64, stride68). Tint
содержит цвет материала/биома, без directional diffuse. Low умножает на явный
shade и сохраняет прежние веса/визуальную модель Low; Medium/High используют
исходный материал и рассчитывают освещение от геометрической нормали. Шейдер
больше не делит цвет на предполагаемый classic factor и не связывает эту
операцию с номером LOD. UV остаются только координатами выборки текстуры.

Разделение проведено в server mesh, demo greedy/skirt, model preview, held items
и instanced entities. Карты при UV-clipping сохраняют shade. В LOD merge-key
добавлен shade: лица с разными весами не объединяются. Обычные quad builders
по умолчанию записывают shade1. Все Rust-конструкторы Vertex проверены компилятором.
С учётом восьми instance attributes суммарно используется 16 vertex attributes,
в пределах запрошенных стандартных limits; проверены расположение и отсутствие
пересечений locations. Новая схема ещё не проверялась на реальном Vulkan pipeline.

  https://github.com/X0nk/Bliss-Shader/blob/Stable/shaders/dimensions/all_solid.fsh
  Проверены отдельные color, UV, normalMat, VanillaAO и tangent для normal maps.

Это самостоятельное исправление нашего WGSL/mesh contract. Код BSL/Bliss не
скопирован в runtime; полная система PBR/TBN/AO, shadow filtering, lightmap,
TAA и остальные эффекты этих шейдерпаков не объявляются перенесёнными.
Нормальное изменение света при физическом повороте геометрии сохраняется;
неправильное дополнительное изменение исходного цвета убрано.

Регрессии: повороты UV 90/180/270 при 16 вариантах поворота модели, с UV-lock
и без него, не меняют геометрию/нормали/diffuse; tint не содержит shade; каждый
