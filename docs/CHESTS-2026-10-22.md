# Серверные сундуки, 22 октября 2026

Добавлен отдельный renderer block entities для обычных/двойных, trapped,
ender и copper chests (включая exposed/weathered/oxidized и waxed варианты).
Статическая block model у сундука задаёт только particle texture, поэтому
прежний путь block-model meshing сам по себе не мог показать корпус/крышку.
Используются исходные ModelPart слои из entities.json.gz и локальные официальные
64×64 PNG entity/chest. Изображения и UV не рисуются заново и не ресемплируются.

0x07 декодируется как BlockPos, unsigned event byte, unsigned parameter byte,
VarInt block registry ID. Для сундуков принимается event=1; parameter>0
означает наличие зрителей и открывает крышку. Событие действует только если
блок по позиции совпадает с указанным block ID, как в ClientLevel.blockEvent.
Это не команда открыть локальное меню: событие другого игрока меняет только
видимую крышку. Прочие block event types пока сохраняют unhandled diagnostics.

Крышка/замок используют ChestModel, исходные четыре rotationAround(.5,0,.5)
матрицы, шаг ChestLidController 0.1/тик, интерполяцию и 1-(1-open)^3 перед
поворотом -open*PI/2. При развороте движения сохраняется текущая степень открытия.
Фаза привязана к монотонному времени 20 ticks/sec; точное соответствие фазе
Minecraft.tick не доказано. Повторный одинаковый viewer count не перезапускает
анимацию. Двойные сундуки используют max двух половин, сосед определяется по
facing/type с проверкой согласованности состояний.

Состояние публикуется через immutable SessionReport. Между входящими пакетами
мешер получает запросы для продолжающегося движения; завершённые позы/текстуры
кэшируются. Неподвижная геометрия блоков сохраняет быстрый путь предыдущего цикла.
Вершины имеют local origin и сохраняют точность рядом с границей мира. Low
использует отдельный classic shade; Medium/High — прежнее динамическое освещение.
Свет от сервера и полное vanilla освещение этим изменением не реализованы.

События очищаются при смене уровня, выгрузке/замене блока и замене полной колонки.
Последнее сверено с LevelChunk.replaceWithPacketData -> clearAllBlockEntities:
нельзя переносить состояние старого ChestLidController на новую block entity.

## Эталон и проверки

`tools/reference/ExportChestEvents.java` вызывает CPU-only методы оригинального
JAR 26.2, SHA-1 2dc72797acbc1b63fc16a11c4ac393605f453754:

- 12 StreamCodec пакетов chest/trapped/ender/copper, viewer counts 0/1/255;
- 36 тиков ChestLidController с разворотами и пятью partial tick samples;
- 4 ChestRenderer transformations и исходные connected directions;
- 33 реально posed ChestModel roots: single/left/right, 11 фаз открытия.

`data/26.2/chest-events.json.gz`, SHA-1 в reference.json. Rust проверяет packet
bytes/обрезанные данные, шаги/интерполяцию, матрицы, геометрию/UV каждой из 33 поз
на всех 4 facing (132 случая), неподвижное cache reuse, отсутствие новых слоёв
текстур при анимации и согласованное открытие двух половин. Localhost TCP fixture
передаёт реальное изменение блока, block entity NBT и оригинальное событие:
в live report есть открытая крышка, packet 0x07 не попадает в unhandled.

264 проверки прошли: 231 library, 11 world CPU (включая benchmark), 1 epoch CPU,
16 localhost TCP, 5 Naga. Clippy all-targets -D warnings, fmt, release/cmp/plist OK.
GPU/окно/внешний сервер не запускались после WindowServer инцидента. Визуальный
результат в живом окне пока не подтверждён. Пользовательские настройки не менялись.

Не завершены: shulker/barrel/прочие block entity renderers и события, звуки,
Christmas texture override, полный lightmap/brightness combiner и аппаратный
профиль. В shader paths не переносились новые BSL/Bliss изменения.

Последний лог пользователя также содержит configuration custom_payload 0x01,
set_default_spawn_position 0x61, set_time 0x71, set_chunk_cache_center 0x5e,
game_event 0x26. В этом цикле они не маскировались пустыми обработчиками и
остаются задачами синхронизации наряду с passengers, advancements, damage и
level events. Конфигурация/первый чанк из этого лога успешно декодированы;
это не доказывает полного покрытия протокола. Общая цель не завершена.
