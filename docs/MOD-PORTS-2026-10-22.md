# Перенос модов, 22 октября 2026

Источник — четыре JAR из указанной пользователем папки ElyPrismLauncher.
Версии, SHA-256, лицензии и хэши эталонов: `data/mods/reference.json`.
Исходные моды и настройки лаунчера не изменялись. Runtime остаётся Rust/WGSL;
Java используется только инструментами разработки для получения эталонов.
Перенос всех возможностей этих модов **не завершён**.

| Компонент | Подключено к клиенту | Осталось |
|---|---|---|
| Zoomify 2.17.0 | Физическая C, удержание/переключение, колесо, плавные переходы, чувствительность и покачивание; отдельное меню настроек | Вторичный зум, spyglass, звуки/overlay, cinematic camera, пресеты; `affectHandFov=false` пока не реализован |
| 3d-Skin-Layers 1.11.4 | Кэшированные объёмные наружные слои локального скина, рука, прозрачность, скрытые грани, corner cuts, fast render, дальность и настройки частей | Точные upstream offsets/pivots всего player model, удалённые игроки, skull/item integrations |
| Sodium 0.9.2 | Directional visibility graph секций, кэш обхода, консервативное отсечение серверного terrain | Полный backend, region batching/multidraw, allocator, compact vertices, полная translucent sorting, AO/light/fluid pipeline |
| ViaFabricPlus 5.0.3 | Библиотека декодирования mapping v2, каталог версий и граф маршрутов; данные встроенного ViaVersion | Connection pipeline, переписывание пакетов/состояния, ViaBackwards/Legacy, предметы/чанки/registry/entity переводы; старые серверы пока не поддерживаются |

Zoomify: 14 кривых по 101 значению и доступные обратные функции сравнены с JAR;
100 тиков переходов с четырьмя partial-tick значениями покрывают смену направления,
колесо, отрицательные ступени и сброс. Общий аккумулятор колеса используется
зумом и хотбаром. Математика перенесена с сохранением особенностей исходных EXP
кривых, без замены типовыми easing-функциями.

3D-слои: 48 эталонов сравнивают положения вокселей, UV, скрытые грани и corner
cuts для обычных/slim частей, разной альфы и fast render. Отдельно проверены
наружные нормали. Базовые части тела рисуются до прозрачных слоёв; avatar pipeline
пишет глубину. Этот графический путь пока не проверен запуском окна.

Sodium: 32 эталона opaque-секций совпадают с DirectionalVisGraph JAR. Граф
публикуется атомарно вместе с соответствующими мешами. Неизвестные/неполные
модели не создают заслон; отсутствующие секции внутри области открыты. При
слишком большой области обход отключает отсечение. Камера меняет кэш при
переходе границы секции; shadow pass не отсекается этим графом.

ViaVersion: сравнены таблицы из 26 mapping-ресурсов, каталог содержит 52 записи.
Все таблицы, которые исходный array loader читает успешно, совпадают по каждому
ID. Одна legacy items-таблица 1.12→1.13 требует отдельного sparse holder: исходный
обычный array loader тоже выбрасывает ошибку; Rust пока отклоняет этот путь.
Изменение номера handshake без преобразования пакетов не добавлялось.

Дополнительно исправлен dispatch standalone block_entity_data: Play 0x06.
Play 0x07 — block_event; он больше не попадает в NBT-декодер табличек.
TCP regression передаёт оба пакета через настоящие framing/compression/session.

Проверки: 172 library, 12 loopback TCP, 5 Naga и 7 ресурсных geometry-тестов —
**196 passed**. Clippy all-targets с `-D warnings` проходит. GPU, окно и внешние
серверы не запускались; прирост FPS и визуальная идентичность не измерены.
Логи: `.cache/mod-reference/mod-{lib,network,shader,geometry}-tests.log` и
`mod-clippy.log`. Лицензии портированных компонентов сохраняются в `LICENSES/`
и при упаковке копируются в Resources/Legal приложения.
